esp32‑git

A minimal git client for ESP32 + SD card — verified against stock git.

esp32‑git lets firmware on an ESP32-C3/S3 (built for the Xteink reader family) keep a real git repository on the SD card: notes committed on the device are plain commits that any PC with stock git can log, check out, and push — and history written by desktop git syncs back onto the device.

Getting started (host)

git clone https://github.com/T-Damer/esp32-git.git
cd esp32-git
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure   # every claim is anchored to real git

Using it in firmware

#include "esp32_git.h"

const esp32git_identity me = {"Vault User", "vault@example.com"};

// one-time: create .git/ on the SD card
esp32git_init("/sdcard/vault");

// stage and commit note changes
esp32git_add("/sdcard/vault", "notes/today.md");
char sha[41];
esp32git_commit("/sdcard/vault", &me, "morning notes", sha);

// sync: fast-forward only, fails cleanly when histories diverge
esp32git_push("/mnt/backup/vault.git", "main", "/sdcard/vault");
esp32git_status st = esp32git_fetch("/mnt/backup/vault.git", "main", "/sdcard/vault");
if (st == ESP32GIT_REMOTE_DIVERGED) {
  // surface a conflict notice to the user - we never merge silently
}

How it stays small

  • Streaming SHA-1 (~120 lines) and zlib framing over the tiny uzlib; no dynamic allocation in steady state beyond two bounded scratch buffers.
  • Objects are written loose exactly like git stores them — so nothing needs a pack writer to be correct.
  • The staging index is a documented sidecar (.git/esp32git-index) stock git ignores; native index-format support is a drop-in upgrade if needed.
  • File I/O sits behind a handful of calls, ready to map onto an SD-card HAL (e.g. CrossPoint’s HalStorage) for on-device builds.

Roadmap

  1. smart-HTTP transport (/info/refs, upload/receive-pack) over TLS;
  2. packfile reading for fetches against hosting providers;
  3. PlatformIO library registration + HalStorage backend;
  4. native .git/index format (optional).
